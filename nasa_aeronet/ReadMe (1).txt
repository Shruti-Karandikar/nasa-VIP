This folder contains instructional materials for teaching and learning how to access, analyze, and interpret Level 2 AERONET data using the Tucson station as a case study. These materials are intended for students, early-career researchers, and anyone new to aerosol data analysis using NASA's Aerosol Robotic Network.


Contents
- AERONET Data Guide.pptx: Slide presentation covering AERONET background, data levels, access, and analysis
- AERONET_Full_Speaker_Script.docx: Slide-by-slide speaking notes for presentations
- AERONET_Detailed_Humanized_Script.docx: A more detailed and accessible version of the speaker script
- Tucson_Level2_AERONET_File (.lev20): Sample data file for hands-on analysis
- Python notebooks or .py scripts (optional): For visualizing and analyzing AERONET data


How to Use These Materials
1. Start with the slide deck to introduce AERONET, its scientific value, and how to navigate the website.
2. Use the speaker script(s) to guide your presentation or self-study.
3. Download the Level 2 AERONET data (Tucson example included) from https://aeronet.gsfc.nasa.gov
4. Follow the Excel or Python steps to load, clean, and analyze the data.
5. Try case studies such as seasonal AOD trends, AOD vs. Angstrom exponent plots, and water vapor comparisons.
